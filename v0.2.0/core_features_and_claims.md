Maxwell’s Demon Detector v2

A Rust, terminal-first, realtime network-stream analyzer that visualizes lawful packet traffic as an animated ASCII landscape and highlights anomalous structure using rolling information-theoretic metrics.





The end state is a system whose core claim is measurable: how quickly and how reliably does it detect a change in structure in a stream when marginal rates may remain stable—the central “Maxwell demon” narrative in your original README.
